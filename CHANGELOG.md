# Changelog

## 0.1.0 (2026-10-09)

First public release.

Ruspini partitions and cumulative fuzzy terms, a sparse monotone fuzzy scorecard
fitted by bound-constrained L-BFGS-B, rank-based ROC AUC, Brier score and expected
calibration error, a synthetic loan generator, the `fuzzyscore demo` command,
a test suite with coverage above 90 percent and GitHub Actions workflows for
continuous integration and tagged releases.
